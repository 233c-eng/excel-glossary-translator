# Excel 术语智能翻译脚本

## 🚨 解决的业务痛点
在本地化/翻译行业中，人工翻译Excel术语表常面临两大痛点：
1. **效率极低**：需要逐词复制粘贴到大模型对话中。
2. **一致性差**：同一术语在不同行容易出现译文不一致，导致QA校验困难，上下文割裂。

## 💡 解决方案
基于 Python 调用智谱 GLM API，实现批量自动化处理：
- **Prompt工程约束**：通过设定专属的 `system` 角色（“只翻译，不解释，不加标点”），保证输出纯粹。
- **一致性保障机制**：通过设定极低的 `temperature=0.1`，抑制大模型的随机发散，从工程层面解决同一术语多次翻译结果不一致的问题。
- **工程鲁棒性**：包含 `try-except` 异常捕获，个别术语翻译失败不会导致程序崩溃；API调用间隔1秒，防止触发限流。
- **自动化处理**：基于 `pandas` 库直接读取和写入 `.xlsx` 文件，实现「输入英文词表 -> 输出中文词表」的完整闭环。

## 🛠️ 技术栈
Python · 智谱GLM API · Prompt Engineering · Pandas · Excel数据处理

## 🚀 如何运行
1. `pip install pandas openpyxl zhipuai`
2. 在代码中替换你的智谱API Key（请勿直接提交真实Key到公开仓库）。
3. 将包含英文术语的 `input.xlsx` 放在桌面。
4. 运行 `python translate_terms.py`，脚本会自动生成 `output.xlsx`。
